Delete companies from CSV

Upload a CSV containing company UUIDs and permanently delete those companies.
How to use
  • Upload — drop a CSV containing company UUIDs (you can use an export CSV — just pick the ID column).
  • Select column — choose which column contains the UUIDs, then confirm deletion.
  • Irreversible — this action cannot be undone. Export your companies first if you need a backup.

Salesforce Instance Migration

Swap Salesforce source record IDs on companies — patches both the v1 sourceRecordId and v2 metadata.source.recordId fields.
How to use
  • CSV format — your CSV must have a PB company UUID column and a New Salesforce ID column. An Old Salesforce ID column is optional.
  • What it patches — for each row, sets sourceRecordId (v1) and metadata.source.recordId (v2) to the new Salesforce ID. Both source system fields are set to salesforce. All other company data is left unchanged.
  • Old ID archival — if you map an Old Salesforce ID column and enable "Move old ID to a text field", the old value is written to a text custom field of your choice for reference.
  • Preview first — use the Preview step to check which rows will be migrated before running.
